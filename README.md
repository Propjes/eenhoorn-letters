# 🦄 Eenhoorn Letters

Een simpel letterspel voor kinderen: er verschijnt een grote letter op de kaart en je kiest uit vier antwoorden welke letter het is.

## Bestanden

- `index.html` — de pagina
- `style.css` — de styling
- `game.js` — de spellogica
- `README.md` — dit bestand

## Spelen

Open `index.html` in een browser. Je speelt 10 rondes; elke goede letter levert 10 punten op.
